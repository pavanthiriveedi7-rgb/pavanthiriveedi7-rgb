### 🔎 Project 02 · Semantic Search Engine

A search system that converts text into vector embeddings and retrieves conceptually similar information instead of relying only on keyword matching.

| | |
|:--|:--|
| **Problem** | Keyword search misses results that mean the same thing but use different words |
| **Approach** | Encode text into embeddings, store them with metadata, and retrieve by semantic similarity |
| **Technology** | Python • Sentence Transformers • `all-MiniLM-L6-v2` • Embeddings • ChromaDB • Vector Search |
| **Outcome** | A working search pipeline that finds meaning-based matches from a persistent vector collection |

**Key details**
- 384-dimensional embeddings
- Semantic similarity matching
- Vector storage with metadata
- Persistent ChromaDB collection
