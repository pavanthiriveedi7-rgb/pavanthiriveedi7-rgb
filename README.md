### ◉ Project 01 · Real-Time Defect Detection (YOLOv8)

</div>

> **Real-time computer vision pipeline for industrial surface defect detection and classification, built on YOLOv8.**

<br/>

<table>
  <tr>
    <td width="25%"><strong>◖ Problem</strong></td>
    <td>Manual visual inspection in manufacturing is slow, inconsistent, and prone to human error.</td>
  </tr>
  <tr>
    <td><strong>◖ Why It Matters</strong></td>
    <td>Automated defect detection improves quality control, reduces waste, and enables real-time production monitoring.</td>
  </tr>
  <tr>
    <td><strong>◖ Approach</strong></td>
    <td>
      1. Collect and annotate defect image dataset<br/>
      2. Preprocess images (resizing, normalization, augmentation)<br/>
      3. Configure and train YOLOv8 object detection model<br/>
      4. Optimize for real-time inference speed<br/>
      5. Evaluate using mAP, precision, recall metrics<br/>
      6. Build inference pipeline for live defect detection
    </td>
  </tr>
  <tr>
    <td><strong>◖ Technology</strong></td>
    <td>
      <code>Python</code> • <code>YOLOv8</code> • <code>Ultralytics</code> • <code>OpenCV</code> • <code>PyTorch</code> • <code>Computer Vision</code> • <code>Object Detection</code>
    </td>
  </tr>
  <tr>
    <td><strong>◖ Outcome</strong></td>
    <td>A trained YOLOv8 model capable of detecting and classifying surface defects in real-time, suitable for industrial quality inspection pipelines.</td>
  </tr>
</table>

<br/>

**◖ What I Learned**
- YOLO architecture and anchor-free detection
- Image annotation and dataset preparation for object detection
- Training object detection models on custom datasets
- Real-time inference optimization
- Evaluating detection models using mAP and confusion matrices
